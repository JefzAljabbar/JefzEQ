# JefzEQ — Tahap 2

Build APK (tanpa Android Studio):
1. Buat repo GitHub baru, upload isi folder ini (termasuk `.github`).
2. Tab **Actions** → workflow **Build APK** → tunggu selesai.
3. Unduh artifact `JefzEQ-debug-apk`, ekstrak, install `app-debug.apk`.

Atau Android Studio: Open folder → Build > Build APK(s).
Nyalakan switch di aplikasi, lalu putar YouTube.
